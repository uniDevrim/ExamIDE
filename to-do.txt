Variable Randomization (Parametric Questions): 
Instead of giving everyone the exact same question variables,
randomize constants or input ranges. For example:
Student A: "Write a function that returns numbers divisible by 3."
Student B: "Write a function that returns numbers divisible by 7."
Question Order Shuffling: Shuffle the order of questions 
for each student so they cannot easily copy progress off
the screen of the student sitting next to them.
